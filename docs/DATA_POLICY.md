# 数据与发布内容

公开软件目录包括自编程序、原研究下游检查点、训练统计量、汇总指标、20 条去除转写和视频的数值记录，以及明确标记的合成样例。

不包含原始比赛数据集、PKL、原始视频、音频、转写文本、原论文全文、上游 BERT / Whisper 模型包、OpenFace 安装包。检查点只包含自训练下游网络 state_dict，不包含上游预训练语言模型。

`local_data/`、`exports/`、`uploads/`、Python 环境、运行日志和 `.env` 均被 Git 忽略。发布脚本另外使用文件白名单，因此不会仅靠忽略规则排除私人内容。历史案例中的 S01–S20 是便于演示的顺序编号，对应原专项数据 01–20；不得将其解释为匿名化原始数据集的再分发许可。

软件代码 MIT 许可不覆盖第三方数据的授权。随附模型与统计结果用于说明本研究，原始数据及上游组件沿用各自来源的许可；本项目不主张其所有权，也不提供这些数据的下载镜像。

安装完成后应用不调用云端模型、不收集遥测。默认 HTTP 服务只绑定本机回环地址，不提供账户、访问控制或公网部署功能。
