TriSense Studio 本地版 API

此文档描述下载后运行的 Python 本地版；GitHub Pages 网页直接在浏览器中运算。API 默认位于 http://127.0.0.1:8765，无需密钥。只用于单机研究演示。

返回工作台 · 下载并启动 Python 版后，在 /openapi.json 查看机器可读规范

方法 / 路径作用
GET /api/health版本、CPU 与模型文件状态
GET /api/research历史实验汇总与评价协议
GET /api/samples样本目录及本地可运行状态
GET /api/samples/S01单条历史结果
POST /api/analyze运行内置 / 本机样本，JSON 请求
POST /api/upload运行上传 NPZ，multipart/form-data
GET /api/example下载合成接口样例

分析参数

{
  "sample_id": "synthetic",
  "predictor": "q3",
  "mode": "audio+vision",
  "rate": 0.3,
  "location": "middle"
}

predictor：q3 / ensemble；mode：none / audio / vision / audio+vision；rate：0–1；location：early / middle / late。上传接口使用同名表单字段，以 file 替代 sample_id。

返回结果

prediction：三类概率与强度；baseline：干预前输出；attribution：精确 Shapley、相对作用与守恒残差；features：可用性和显示用热图；local_effects：音视频滑窗遮挡；source / synthetic：来源标识。索引从 0 开始，窗口 stop 不包含在内。

输入错误

409：本地样本特征不存在；413：上传请求过大；415：扩展名不支持；422：数组、schema 或参数不符合接口。NPZ 内禁止对象数组，不加载不可信 pickle。完整字段约束见项目 docs/INPUT_FORMAT.md。
