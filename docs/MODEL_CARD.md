# 模型与研究协议

## 推理架构

MaskedFusionNet 将 768 / 74 / 35 维特征分别经 Linear、LayerNorm、GELU 投影到 96 维。逐位置门控使用掩码 softmax，只在可用模态间分配权重。融合后加入可用性编码与位置编码，经过两层残差时序卷积，结合注意力池化与均值池化，送入三分类头与强度回归头。下游网络共 165,128 个参数。

原训练目标为加权交叉熵 + 0.45 × SmoothL1，AdamW、学习率 0.0008、batch size 64。原标签按强度 `<0 / =0 / >0` 映射负向 / 中性 / 正向；推理分类由分类头 argmax 给出，不用回归输出符号强制覆盖分类。

Q2 模式使用两个不同训练检查点，以 0.75 × baseline + 0.25 × robust 混合类别概率和回归输出；回归混合后截断到 [−3,3]。Q3 模式是独立训练的单模型。UI 的“四模型比较”是 MLP、BiGRU、Transformer、MaskedFusionNet 的历史三种子实验，本软件并未实现四个模型的实时切换或训练。

## 可解释性定义

先固定完整当前输入的预测类别 c，再定义 `v(S)=p_c(x_S)`。不存在的模态将特征和可用性同时设为零。枚举三个参与者的全部 8 种子集，按 Shapley 权重 `|S|!(2−|S|)!/3!` 加权边际变化。

返回带符号的贡献、按绝对值归一化的相对作用、空集概率与全模态概率，并校验贡献之和等于后两者的差。相对作用在全部贡献为零时返回三个零，不强行均分为 1/3。负贡献表示抑制当前类别，不能解释为“该模态本身情感负向”。

局部分析在音视频内容位置使用宽 3、步长 2 的滑窗，补上尾部窗口；短序列缩短窗口。差值是原始当前类别概率减去遮挡后同一类别概率。完全不可用的模态返回空列表。第一层干预改变当前输入后，局部解释针对干预后的当前输出。

## 历史实验

训练 3,395 条，内部验证 728 条。四架构各 3 个种子（2026/2027/2028），最多 16 epoch、patience 4，按 Macro-F1−0.08×MAE 选模。比较协议不使用缺失增强。误差条为种子间样本标准差，n=3，不是置信区间。

原压力实验使用内容位置 30% 的中部缺失：文本、语音、视觉和同步缺失。文本缺失先替换为 UNK，再重新编码 BERT；结果来自 `paper_stress.py` 生成的汇总。本软件不含这部分重新编码运行环境，仅展示其历史结果。

正式 Q2 增强模型另有局部缺失训练策略；最终集成也在内部验证场景上选权重。不能把其指标与无增强的架构比较描述成完全相同的训练条件。模型未使用附件三、四的真实标签，这两组本来就没有标签。

## 限制

- 内部验证参与早停和选模，无独立外部泛化结论。
- 只接受训练特征协议兼容的数据，无法保证任意视频、语种和采集设备上的表现。
- 第一问自行提取的声学与视觉特征不自动等价于题给预提取特征。
- 概率未校准，不等于“判对概率”；三类输出不是心理健康诊断。
- Shapley 是指定零基线下的模型归因，不能据此建立因果结论。
- 本次工程迁移核对了前向计算和接口，没有重新计算原数据集的全部指标。
