# AI 协作开发记录

本软件在已有数学建模研究基础上，采用 AI 协作开发方式完成产品拆分、接口设计、代码编写、排错、测试用例和文档整理。开发工具包括 OpenAI Codex；模型训练、检查点和历史指标来自已有研究工程。

工程流程：读取原始实现与结果 → 明确真实推理和历史展示的边界 → 提取兼容网络与归一化 → 实现输入校验和解释接口 → 制作交互界面 → 执行自动化测试和原实现对齐 → 浏览器验收 → 整理发布内容。

验证不是单纯复述 AI 的生成结果：使用原 `q2_pipeline.py` 中的实际函数做参考，逐项比较输入张量和前向输出；对 Shapley 检查效率公理，对完整视觉缺失检查零贡献，对错误数组和不可信文件检查拒绝路径。

简历可以描述为“基于已有多模态研究，采用 AI 协作开发构建本地分析软件，完成模型服务封装、交互式缺失实验、可解释结果展示和自动化测试”。应按实际承担的工作说明贡献，不把 AI 生成的内容描述为未经工具参与的独立成果，也不把合成样例当作真实业务效果。
