如何开始

  1. 进入分析工作台，浏览 20 条真实实验数值记录。
  2. 点击“使用合成样例试运行”，验证本机推理与导出流程。
  3. 上传符合接口的 NPZ，或用 scripts/import_local.py 导入你有权使用的附件四数据。
  4. 选择模型和音视频遮挡范围，点击运行，导出 JSON 或 CSV。

输入接口

schema
mosei-aligned-50-v1
text / audio / vision
50×768 / 50×74 / 50×35 数值数组
text_bert
3×50 整数数组：token ID、attention mask、segment ID
格式与边界
单样本 NPZ，≤8 MB；有限数值，禁止对象数组。输入须保持题给特征语义与标准化前尺度。

使用范围

  • 软件接收兼容的预提取特征。当前不支持上传任意视频后直接给出可靠情感预测，也不把第一问自提取特征直接套入第二问模型。
  • 内部验证集参与早停与模型选择；展示的性能不等于对外部数据的泛化保证。
  • 类别概率没有经过校准；Shapley 与局部遮挡解释的是模型，不是人的心理因果关系。
  • 比赛原始数据、转写文本和视频不随公开仓库发布。上传文件只在内存中处理，软件不向外部服务发送数据。
  • 服务默认仅监听 127.0.0.1；没有账户系统，不应直接作为公网服务部署。
